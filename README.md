# 🛤️ Arduino Line Follower Robot

## 📌 Overview
This project creates a **line follower robot** using IR sensors and an Arduino.  
The robot follows a black line on a white surface by controlling two DC motors.

---

## 🛠️ Hardware Required
- Arduino Uno/Nano  
- 2 IR Sensors (for line detection)  
- L298N Motor Driver  
- 2 DC Motors + Chassis + Wheels  
- Battery Pack (6–12V)  

---

## 🔌 Wiring
- **IR Sensors**  
  - Left Sensor → D2  
  - Right Sensor → D3  

- **Motors (via L298N)**  
  - IN1 → D4  
  - IN2 → D5  
  - IN3 → D6  
  - IN4 → D7  

---

## ▶️ Usage
1. Place the robot on a track (black line on white background).  
2. Upload the code to Arduino.  
3. Power the robot → it follows the line automatically.
